# Desktop Snow

Небольшое Windows-приложение с белым снегом поверх рабочего стола. Снежинки плавно падают на всех мониторах, не перехватывают мышь и постепенно собираются в сугроб над панелью задач.

## Быстрый запуск

Готовый файл после сборки:

```text
dist\DesktopSnow.exe
```

Запустите его двойным щелчком. Для управления нажмите правой кнопкой по синей снежинке рядом с часами.

## Возможности

- белые круглые снежинки и снежинки-кристаллы;
- естественное покачивание ветром;
- постепенное накопление и сглаживание сугроба;
- поддержка нескольких мониторов и разного DPI;
- прозрачность для кликов — приложение не мешает окнам и значкам;
- три уровня интенсивности;
- пауза, очистка сугробов и отключение режима «поверх окон»;
- автозапуск вместе с Windows;
- автоматическая реакция на смену разрешения и положения панели задач;
- один экземпляр приложения.

## Установка

Откройте PowerShell в папке проекта и выполните:

```powershell
.\install.ps1
```

Скрипт копирует приложение в `%LOCALAPPDATA%\DesktopSnow`, создаёт ярлыки на рабочем столе и в меню «Пуск», затем запускает снег. Для автозапуска сразу после установки:

```powershell
.\install.ps1 -AutoStart
```

Права администратора не нужны.

## Управление

В меню значка рядом с часами доступны:

- **Поставить снег на паузу / Продолжить снег**;
- **Интенсивность**: лёгкая, обычная или сильная;
- **Очистить сугробы**;
- **Поверх всех окон**;
- **Запускать вместе с Windows**;
- **Выход**.

Двойной щелчок по значку ставит анимацию на паузу или продолжает её.

После выбора настройки меню остаётся открытым, поэтому можно сразу изменить несколько параметров. Чтобы закрыть меню, нажмите вне него или клавишу `Esc`.

## Сборка из исходников

```powershell
.\build.ps1
```

Используется встроенный компилятор .NET Framework 4.8. Сторонние библиотеки и доступ к интернету не требуются.

## Удаление

1. В меню снежинки отключите **Запускать вместе с Windows** и выберите **Выход**.
2. Удалите `%LOCALAPPDATA%\DesktopSnow`.
3. Удалите ярлыки `Desktop Snow` с рабочего стола и из меню «Пуск».

Настройки находятся в `HKEY_CURRENT_USER\Software\DesktopSnow`. Приложение не использует сеть и не собирает данные.
